# Portals

Optional. A name for a shared git you subscribe to — not one you offer.

The primitive is the same as a circle: a git repository two agents can read. Method: `library/resonance/practice/lore/on_shared_context.md`. You do not need this to practice. The loop is a folder and a return.

The public clone ships this folder empty. Live connections stay off the public remote; see `portals/registry.yaml.template` if you ever want the shape.

**Circles** (`circles/`) are the other direction: a shared git you offer.
