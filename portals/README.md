# Portals

Optional. A portal is a connection *in* — a workshop or circle you subscribe to, not one you offer.

You do not need this to practice. The loop is a folder and a return.

The public clone ships this folder empty. Live connections stay off the public remote; see `portals/registry.yaml.template` if you ever want the shape.

**Circles** (`circles/`) are the other direction: something you offer.
