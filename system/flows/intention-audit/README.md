# Intention Audit

**Invocation:** `@intention-audit` (or `@audit`) · offered during `. maintenance` when the active set is large or staleness shows
**Purpose:** Review the whole intention landscape efficiently — determine which intentions the Mage still stands behind — without reading every file.
**Outcome:** A reconciled intention set: each intention affirmed, revised, made dormant, released, or restructured; compass and chains brought back into sync with reality.

---

## The Problem It Solves

Intentions accumulate. The ones practiced regularly grow; others quietly drift, stall, or stop reflecting what the Mage actually wants — and reading all of them to find out costs a whole day. The audit is the batch sweep that keeps the intention compass a *living pointer* instead of an accreting backlog.

## The Core Move

**Invert the labor.** An audit feels like a day because the Mage would read every file. Instead: **Spirit reads everything and does the archaeology; the Mage supplies only the one thing Spirit structurally cannot — the felt-rightness verdict.**

This is the batch-sweep form of the **Compass Divergence Protocol** (`on_intention_architecture.md` §XI). The load-bearing diagnostic is the gap between the Mage's **two compasses** (§X): the *inner compass* (felt-rightness) and the *intention compass* (the aggregate of commitments that accretes from momentum, obligation, and old enthusiasm). "Do I still stand behind this?" = "does this written intention still track my felt-rightness?" **The divergence is the signal.**

## What Makes It Fast

- **Spirit reads; Mage feels.** Spirit reconstructs where each intention *actually* stands from git history, `chains.md` momentum signatures, `compass.md`, and session/briefing traces — not from what the file claims.
- **One-line resonance probes.** Each intention is distilled to its resonance essence + a drift flag. The Mage reacts to the probe, not the file.
- **Concentrate attention where divergence lives.** The clearly-live intentions are batch-affirmed; the Mage's felt-sense is spent only on the genuine probes.

## The Verdict Vocabulary

| Verdict | Meaning |
|---------|---------|
| **Stands** | still resonates as-is |
| **Revise** | still yours but drifted — reframe with Spirit |
| **Dormant** | real but not now — demote, stop tracking as live (→ `dormant/`) |
| **Release** | no longer yours — compost (→ `archive/`), no guilt |
| **Merge / Split** | structural — restructure with Spirit |
