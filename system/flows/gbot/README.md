# Grok Bot

Spirit acts on Grok Bot teammates from the Forge via the unofficial `gbot` CLI. The Mage does not sit in the app.

**Invocation:** `@gbot`

Read-only by default. Writes (`send` / `create` / `update` / `delete`) run only when this invocation names the target and the Mage has accepted the meter.

Spell: `cast_gbot.md`. Machine facts: `desk/craft/grok_bot_control.md`.
