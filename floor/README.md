# Floor

The partner’s scratch for this chapter — drafts, briefings, working notes. Not the life. That is `desk/`.

The public clone ships this folder empty on purpose.

## What it is for

A session that will not fit in the chat: a briefing to come back to, a half-finished synthesis, a note for the next Spirit. Write it here so the thread can leave the conversation.

It is not an extended mind, and it is not distributed cognition. It is a folder.

## Typical files

- **`briefings/`** — where a chapter left off (`latest.md` when you keep one).
- Working notes for a long piece of work, named for that work.
- Nothing that belongs on the desk as *your* intention or *your* week.

When the chapter is over, harvest what the desk needs and let the rest go.
